YASH PAGARE — PORTFOLIO

Open index.html in a browser to view the portfolio. The site is self-contained and uses the supplied artwork; it does not use generated imagery or external services.

PERSONALISE BEFORE SHARING
1. In index.html, update the description and the “BASED IN INDIA” line if you want to show your city.
2. Replace YOUR_EMAIL@example.com in the mailto link with the email address you want employers to use.
3. Update the study details and software list when you want those specifics shown. They are intentionally broad until confirmed.
4. If you use the portfolio publicly, make sure you have permission to show institute or event marks included in the original designs.

The attached designs are kept in assets/. The project cards, category filters, responsive layout, and image previews work without installation.
